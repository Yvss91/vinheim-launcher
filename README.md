# Vinheim Launcher

Launcher Windows du serveur de roleplay viking **Vinheim RP** (nanos world).

## Installer

1. Installe **nanos world** sur Steam (gratuit). Le launcher peut aussi ouvrir l'installation Steam pour toi.
2. Télécharge `Vinheim-Launcher-<version>-Setup.exe` dans les [Releases](../../releases/latest).
3. Lance l'installateur.

### Avertissement Windows SmartScreen

L'installateur n'est pas signé : Windows affiche « Windows a protégé votre ordinateur ».
Clique sur **Informations complémentaires**, puis sur **Exécuter quand même**.

## Jouer

Ouvre le launcher, puis **Jouer**. L'adresse du serveur est affichée sur l'accueil (bouton copier)
si tu dois te connecter à la main depuis nanos world.
